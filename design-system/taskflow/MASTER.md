# TaskFlow 控制台设计规范

## 设计定位

用于配置任务的开发者控制台。参考 ui-ux-pro-max 的 DevOps monitoring dashboard 检索结果，采用清晰的数据层级、等宽技术字段、安静的状态色；调整为深色侧栏与浅色工作区，适配长时间查看表单和表格。

不使用外部字体或图片 CDN。品牌图标与功能图标采用本地 SVG，界面文案以中文为主。未接入的执行观测入口标记“规划中”并禁用，不展示模拟运行数据。

## 语义令牌

唯一实现来源为 taskflow-web/src/styles/tokens.css。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| canvas | #f5f6fa | 工作区背景 |
| surface | #ffffff | 卡片、表单 |
| sidebar | #172033 | 导航与品牌 |
| ink | #263248 | 主文本 |
| muted | #65738a | 辅助说明 |
| primary | #6b5ce7 | 主操作、选中导航 |
| primary-hover | #5746cf | 主操作悬停 |
| primary-tint | #f0edff | 轻量强调 |
| green | #187b60 | 启用、连接正常 |
| red | #c2414f | 删除、错误 |
| line | #e9ecf2 | 分隔线 |

字体使用系统无衬线字体与中文字体回退；Cron、Handler、JSON、ID 使用系统等宽字体。间距以 4px 为基础；卡片圆角 12px、按钮 7px、侧栏宽 240px。

## 页面与交互

- 工作台：真实任务配置统计、最近五项任务、配置方式分布、时间预览入口。
- 任务管理：名称/状态/处理器筛选、分页、详情、右侧编辑抽屉、启停和软删除确认。
- 时间预览：六字段 Cron、常用规则、时区与未来时间列表。明确预览不执行任务。
- 新建/编辑共用表单；保留服务器错误和未保存内容；版本冲突不自动覆盖。
- 任务详情增加手动执行、运行分页、状态与 Attempt 历史、配置快照。执行按钮为该视图主操作；提交未确认时保留原标识，可查验或重试；自动刷新仅在详情打开时进行，关闭后停止。全局运行总览和告警仍属后续能力。
- 工作节点：真实节点统计、分页、名称/状态筛选、能力和负载、固定派发目标及最近心跳。默认每 5 秒刷新，可暂停；离开或隐藏页面停止请求。查询失败保留旧记录并改为“待刷新”，不继续声称在线；移动端表格转卡片，长标识、Handler 和队列换行。
- 原生 dialog 提供模态焦点限制、Escape 关闭和关闭后焦点恢复。状态和错误同时使用文字，避免仅依靠颜色。
- 使用 SVG 图标、可见焦点、跳转主内容链接、错误提示与重试、加载骨架；遵循 prefers-reduced-motion。
- 768px 以下收起导航；560px 以下表格转为任务卡片，抽屉占满屏幕。375px 起避免页面横向溢出。

## 维护

布局和组件样式集中在 app.css，颜色与字体集中在 tokens.css；页面不内嵌请求地址或数据库配置。新增页面沿用标题、卡片、字段、状态和对话框模式，避免复制另一套设计令牌。
