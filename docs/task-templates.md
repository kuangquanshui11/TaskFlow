# 任务创建业务模板

## 交互与配置

我将订单超时检查、销售报表、库存同步和过期数据清理做成创建任务时的可选模板，让业务用途、基本配置与参数指引出现在同一个流程。客户点击「新建任务」后选择场景；自定义任务保留原有配置入口。首页聚焦任务统计和最近任务，不再展示独立的业务介绍卡片。

| 模板 | 默认建议（Asia/Shanghai，均可调整） | 参数示例 | 业务处理器 |
| --- | --- | --- | --- |
| 检查超时未付款订单 | 每分钟，`0 * * * * *` | `timeoutMinutes=30`、`batchSize=100` | `orderTimeoutCheck` |
| 生成销售报表 | 每天 01:00，`0 0 1 * * *` | `shopId=8` | `salesReport` |
| 定期同步库存 | 每 5 分钟，`0 */5 * * * *` | `warehouseId=12` | `inventorySync` |
| 清理过期数据 | 每天 03:00，`0 0 3 * * *` | `retentionDays=90`、`batchSize=500` | `expiredDataCleanup` |

模板同时填写名称和任务说明，提供参数含义、业务范围与处理器接入要求。客户需要替换示例中的店铺、仓库等标识，确认业务规则，再检查计划与失败策略。模板默认停用、最多尝试一次，避免在业务重复执行约束尚未确认时自动运行或重试；其他默认值沿用原表单。客户可以修改这些值，先手动验证后再启用计划。

选择模板只修改当前表单，不立即保存或执行。修改过草稿后切换模板会显示应用确认；选择保留时，原场景、名称、计划与参数均保留。关闭再创建从新的草稿开始；编辑已有任务不展示模板选择器，也不重写原配置。

## 客户自定义执行时间

所有业务模板和自定义任务共用「执行计划」。客户可以选择常用分钟间隔、每天任意小时分钟、手动触发，或使用高级 Cron。模板卡片不再展示固定频率，选中后显示当前实际计划；指引中的「调整执行时间」会定位到频率控件。

简单分钟模式提供 1、2、3、4、5、6、10、12、15、20、30、60 分钟，自动转换为现有六字段 Cron；60 分钟使用每小时整点。这里只提供能整除一小时的间隔，避免将 `*/7` 这种跨小时不等距的规则描述为均匀的每七分钟。计划按所选时区的日历边界触发，不从保存时刻计时，也不提供任意固定延迟的保证。每天模式支持 00:00–23:59，并校验空时间。

高级模式保留现有 Cron 编辑能力；已有任务中的工作日、秒级等复杂表达式不被转换或覆盖。切换手动再切回定时会保留原计划；调整频率、时间或时区会使旧预览失效，客户可通过真实预览接口确认下次执行时间。提交继续使用原 `cronExpression`、`scheduleType` 和 `timeZone`，不新增后端协议字段。

## 接入状态与流程演示

Admin 的处理器白名单仍是可选标识的来源。对应业务标识未配置时，表单保留待接入标识，显示所需接入步骤、刷新入口，并禁用业务提交；不会自动替换为成功演示处理器。白名单包含标识不代表有在线 Worker 支持它，表单仍提示确认执行节点能力。

客户可以主动选择「先体验调度流程」。此操作选择 `demoSuccess`、在名称和说明中明确标记演示用途，并保持停用；保留客户已调整的计划和参数。页面明确说明不会查询订单、生成报表、同步库存或删除数据，业务参数仅作为配置示例保留。

模板和演示共用既有任务创建 API，不新增协议字段或业务处理器，不写其他服务数据表；真实业务接入需要实现相应 Handler 并完成其独立验收。
